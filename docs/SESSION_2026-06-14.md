## Arc

1. **Dataset hunt → CyberNative.** Fresh HF search (we hadn't done one with the
   precise requirement). Most datasets share our flaw (label-noise fixers like
   CleanVul; function-level C/C++ like PrimeVul). CyberNative DPO (4656 synthetic
   vuln/safe pairs, 243 XSS) fit the shape: self-contained, escaping = the
   discriminator. GPT-5.3 validated 94% pair discrimination on a sample → usable.
   Filtered to 135 clean XSS pairs (dropped 9% garbage, 29% encodeURIComponent
   weak-fix). docs/CYBERNATIVE_DATASET_2026-06-14.md.

2. **v8.4 experiments (continue-train from v8.3.1 adapter; eval on controlled-20
   synthetic + mined-real held-out + gold-core).**
   - **exp1 (synthetic-only):** escaping learnable (controlled 0/20→11/20) BUT
     over-corrects to FP on real code (gold-core DR 64%→14%). Synthetic alone fails.
   - **exp2 (synthetic + 40 clean mined + old anchor):** gold-core MCC +0.517
     (> v8.3.1 +0.447), FAR 18%→2%, escaping 10/20, real-transfer MCC 0.255.
     Recipe = synthetic concept + real anchor.
   - **exp3 (scale anchor 3x with RELAXED filter, 151 noisy pairs):** NOT better.
     gold-core same +0.517 but mined recall WORSE (0.255→0.075). Lesson:
     anchor quality > quantity.
   - **exp4 (the right multiply: 60 UNION clean pairs = exp2's 40 ∪ 31
     GPT-5.3-validated):** NEW BEST. sastbench MCC +0.250 (vs exp2 +0.155),
     recall 17%→29%, gold-core tied +0.511. GPT-5.3 validation showed only 21%
     of mined pairs are clean → clean real CWE-79 pairs are scarce (~60 cap).
     Checkpoint selection: no gain (final best; early checkpoint all-FP).
   - Results docs: RESULTS_v8_4_{cwe79,exp2,exp3,exp4}_2026-06-14.md.

## The strategic reset (most important takeaway)

- **Current flagship (Opus 4.8) clearly beats our 7B on clear cases.** No spin.
- **The "frontier is paranoid / 50% FAR" wedge is DEAD** against current models
  (Opus FAR 10%, DR 91%). That story was true only for Sonnet 4.5 / Gemini 2.5.
- **Remaining defensible wedge = cost (100-1000x) + on-prem.** NOT accuracy.
  Stop claiming accuracy parity/superiority vs frontier.
- **Forward path = distillation.** A strong flagship is GOOD: use Opus 4.8 as the
  TEACHER to break the clean-data scarcity wall (re-label verdicts, generate
  reasoning, expand the clean anchor). ~$30-60 one-time to build a big clean
  train set, then train the cheap on-prem 7B. exp5 = distillation. Positioning:
  "flagship-distilled specialist, $0 on-prem".
