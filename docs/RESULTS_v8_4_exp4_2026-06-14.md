# v8.4-exp4 (clean anchor, the right multiply) — marginal win, ceiling reached (2026-06-14)

Zakhar's push: don't freeze, multiply what worked in exp2. Done correctly this
time (exp3 was the WRONG multiply — noisy quantity). exp4 = exp2 recipe with the
CLEAN real anchor maximized: union of exp2's 40 escaping-keyword pairs + 31
GPT-5.3-discrimination-validated pairs from the scaled pool = 60 clean real pairs
(vs exp2's 40). Plus checkpoint selection (eval intermediate checkpoints).

Key fact from GPT-5.3 validation: only **21% (31/151)** of the relaxed-mined pool
is clean. Clean real CWE-79 pairs are genuinely scarce (~60 total assembled).

## Verdict: exp4 marginally beats exp2, then the ceiling

- **gold-core: tied** (exp4 +0.511 ≈ exp2 +0.517, within n=71 noise), exp4 with
  slightly higher recall (45% vs 41%).
- **sastbench-250 (n=250, the more stable real set): exp4 clearly best** — MCC
  +0.250 vs exp2 +0.155, recall 29% vs 17%. The extra clean anchor recovered
  recall (exp2's weak spot) without breaking precision (FAR 4%).
- mined-heldout n=31 dissents (noisy small-n), but the stable sets agree exp4 ≥ exp2.
- **Checkpoint selection: no gain.** Early checkpoint-50 was all-FP (DR 0);
  recall rose with training; the final checkpoint is the best. The FP-collapse is
  not a late-epoch artifact here.

So Zakhar's instinct was right: pushing exp2 with more CLEAN anchor gave a real,
if modest, gain — recall up on the stable real set, gold-core held. **exp4 is the
new best.** But it is diminishing returns: 40→60 clean pairs moved recall a little,
and clean pairs are capped at ~21% yield. The next gain needs a new clean-data
source, not more of the same.

## Recipe, settled

Best model = **continue-train from v8.3.1 on: clean synthetic XSS (concept) +
maximal GPT-5.3-validated clean real anchor (grounding) + clean old anchor**.
Lessons banked:
- synthetic-only collapses (exp1); noisy anchor poisons (exp3); clean anchor at
  quality + quantity is the lever (exp2→exp4).
- escaping-blindness fixed (0/20 → 10/20) and stable across variants.
- FAR slashed 18% (v8.3.1) → 2-4%; gold-core MCC +0.45 → +0.51.
- recall on balanced real pairs remains the open frontier (DR ~22-45%), capped by
  clean-real-TP scarcity — the original snippet-sufficiency root cause.

## Recommendation

exp4 is a defensible new baseline (best on stable real eval, escaping fixed, clean
FAR). The model path has now delivered a clear, measured improvement and reached
the data-scarcity ceiling. Honest next move: freeze exp4 as baseline and shift to
demand validation (untouched, the riskiest hypothesis, no compute). Raising recall
further is a clean-data-acquisition project (new sources / paid curation), a later
iteration, not a now-blocker.
