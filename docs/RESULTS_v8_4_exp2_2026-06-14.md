# v8.4-exp2 (mixed anchor) — best model on the trusted metric (2026-06-14)

exp1 (synthetic-only) over-corrected to FP and collapsed recall. exp2 adds REAL
vulnerable examples to the train mix: synthetic XSS (135 pairs) + mined-real
CrossVul (40 pairs, real TP+FP) + clean old anchor (58 rows). Continue-trained
from v8.3.1. Test on held-out 31 mined pairs (disjoint), controlled-20, gold-core.

## Results across all three checkpoints

### gold-core (trusted compass, n=71 human+GPT-5.3 consensus)

| model | MCC | DR | FAR |
|---|---:|---:|---:|
| v8.3.1 | +0.447 | 64% | 18% |
| v8.4-exp1 (synthetic-only) | +0.313 | 14% | 0% |
| **v8.4-exp2 (mixed anchor)** | **+0.517** | 41% | 2% |

**exp2 is the best model the project has produced on the trusted metric** —
MCC +0.517 beats v8.3.1's +0.447, with FAR cut from 18% to 2% (far fewer false
alarms), at the cost of recall (64%→41%). For a high-precision ranker this is a
better operating point. (n=71, so the MCC gap has a wide CI; the FAR drop is the
robust part.)

### controlled-20 (synthetic, escaping discrimination)

| model | pair discrimination | MCC |
|---|---:|---:|
| v8.3.1 | 0/20 | 0.00 |
| exp1 | 11/20 | 0.546 |
| exp2 | 10/20 | 0.436 |

Escaping-blindness is fixed: from 0/20 to 10/20. (8/20 still both=TP on the
mechanisms least represented in training.)

### mined held-out (real-code transfer, 31 pairs, the hard verdict)

| model | MCC | DR | FAR | discrimination |
|---|---:|---:|---:|---:|
| exp1 (on 71 mined) | 0.108 | 15% | 8% | 7% |
| exp2 (on 31 held-out) | **0.255** | 19% | 3% | 16% |

Real-transfer MCC more than doubled (0.108→0.255). But recall is still the weak
point: 25/31 pairs are both=FP — the model still misses most real vulnerabilities
on balanced real pairs. The mixed anchor reduced the collapse but did not remove it.

## Verdict on experiment A (mixed anchor): WORKED, partially

- The recipe is validated: **synthetic concept + real anchor** beats both pure
  synthetic (exp1 collapse) and v8.3.1 (paranoid) on the trusted metric.
- escaping-blindness fixed (0/20 → 10/20).
- gold-core MCC is a new project best (+0.517) with a clean 2% FAR.
- Remaining weakness: recall on balanced real pairs (mined DR ~19%). The model
  is now high-precision / lower-recall. More real anchor (only 40 mined pairs +
  9 old TPs this run) should push recall up.

## Why gold-core improved but mined recall didn't

gold-core / sastbench are FP-heavy distributions (gold-core 22 TP / 49 FP), so a
low-FAR conservative model scores well. mined held-out is balanced (31/31), so
missing TPs is penalized fully. exp2 is genuinely better-calibrated toward
precision; recall on real vulnerable code remains the open problem (consistent
with the snippet-sufficiency root cause — real visible TPs are scarce in training).

## Next options

1. **Scale the real anchor**: this run used only 40 mined + 9 old TPs. Mine more
   CrossVul vuln halves (real snippet-sufficient TPs) → push recall up. Cheap.
2. **Ship exp2 as the new baseline** for the ranker product (high precision, 2%
   FAR, beats v8.3.1 on trusted MCC) and move to demand validation.
3. The escaping-discrimination + precision gains are real and shippable; the
   recall gap is the next iteration, not a blocker for a ranker.
