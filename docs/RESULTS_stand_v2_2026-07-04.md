4. Дистанция до цели 0.75-0.80: текущий честный уровень ~0.5-0.6. Разрыв большой; выжимание десятых через тюнинг микса (стиль exp6-9) его не закроет, нужны рычаги из аудита: уникальные TP (дозакрыть relabel), sufficiency контекста (69% TP без уязвимости в сниппете), и только потом файнтюн-итерации.
5. Gold-core (n=71, судья GPT-5.3) как компас для отбора моделей дискредитирован вторично: он систематически переоценивал модель, дистиллированную из родственного учителя. Stand v2 (n=205) — новый дефолтный компас.
