# OSS demo reports — Semgrep → v8.3.1 ranker (2026-06-13)

## Что это

Demo-артефакты для outreach (P4): берём публичный OSS-репо, гоняем Semgrep,
ранжируем findings нашим v8.3.1 ранкером по p_tp, рендерим self-contained
HTML (готов к печати в PDF). Получатель проверяет top-K глазами за час, без
доверия нашему бенчмарку.

Прогон на temp A40 (основной A6000 был в capacity wait), terminate после.
Скрипт: [scripts/run_oss_reports.sh](../scripts/run_oss_reports.sh).
Артефакты: `data/practical/oss_reports/{sarif,html}/`.

## Sanity: top-5 Ghost (проверено руками)

Все пять — XSS-синки, ровно CWE-79, где модель сильнее всего (per-CWE
MCC +0.34):
- `dangerouslySetInnerHTML` из non-constant (2 шт, React .tsx)
- Mustache triple-brace unescape `{{{...}}}` (3 шт, .hbs)

Это правдоподобные реальные кандидаты, не мусор. Ранкер выносит наверх
осмысленное.

## Честные ограничения (для внутреннего понимания, НЕ для получателя)

1. **Узкий диапазон p_tp.** Медиана 0.52-0.68, max ~0.8, на Ghost 90%
   findings выше 0.5. Модель склоняется к TP на большинстве semgrep-findings
   и слабо разделяет по абсолюту. Для ранкера это терпимо (порядок всё
   равно выносит XSS наверх), но «фильтрации шума» из этих чисел не
   продать — только «сортировку по confidence». Это согласуется с
   позиционированием ranker-not-filter.
2. **Ground truth нет.** Это произвольные OSS-репо, никто не знает истинную
   долю TP. Числа выше — это p_tp модели, НЕ accuracy. Контролируемые
   метрики только на репо с известными уязвимостями (ywh+DVWA, см.
   YWH_DVWA_EVAL, MCC 0.42).
3. **Snippet-window.** top-K проверены глазами (правило проекта), но это
   semgrep-вырезки; для disclosure нужна ручная проверка полного файла.
   Эти отчёты — «отсортированный список с confidence», НЕ «найдены RCE».

## Использование

HTML self-contained, печать в PDF через браузер (Ctrl+P → Save as PDF).
Вложение к холодному письму. Формулировка получателю: «вот ваши N алертов
Semgrep, отсортированные нашей локальной 7B по confidence, гляньте top-15
и скажите honestly: порядок осмысленный?». Не «мы нашли баги», не «это FP».
