## Mechanism (что произошло)

Гипотеза по Lesson 12 (FP distribution mix matters more than total count):

1. Llama regenerated reasoning имеет **другой структурный синтаксис** vs
   original DeepSeek (sentence length, hedging language, конкретные
   variable references).
2. Этот синтаксис стал **новым stylistic anchor** для модели.
3. На in-domain test (CVEFixes-style) изменение приемлемое (MCC −0.12).
4. На OOD SastBench (multi-project, разные стеки) модель потеряла какой-то
   важный feature что v8.3.1 случайно подхватил из original boilerplate
   (возможно "vulnerability was found in" корреlировал с TP-кейсами
   достаточно сильно чтобы быть load-bearing).

То есть Llama reasoning **чище** для человеческого читателя, но
случайно убрал stylistic feature который **служил** verdict signal.
Это **inverse Goodhart**: чем чище reasoning, тем хуже verdict accuracy.

## Trade-off

| Aspect | v8.3.1 | v8.3.2 |
|---|---|---|
| MCC SastBench-250 | +0.177 (defensible pitch) | −0.107 (катастрофа для pitch) |
| FAR | 23% (ranker работает) | 55% (paranoia вернулась) |
| Reasoning attachable? | Нет (hallucinated CVEs) | Да (snippet-grounded, varnames) |
| 150× cost wedge claim | Стоит на defensible MCC | Стоит на ничём |
| PDF outreach ready? | Pretty без reasoning | Pretty с rich reasoning, но base модель weaker |

## Три стратегических варианта (decision deferred)

### A. v8.3.2 заменяет v8.3.1 полностью

- ✅ Outreach PDF имеет rich reasoning
- ❌ MCC -0.11, cost wedge pitch разрушен
- ❌ Production ranker priority screen стал бесполезным

### B. Двойной adapter (v8.3.1 = ranker, v8.3.2 = reasoning text)

- v8.3.1 для p_tp ранжирования (high accuracy)
- v8.3.2 для filter mode на top-K (high quality reasoning)
- Production pipeline: ranker → top-10 → reasoning через v8.3.2
- ✅ Лучшее из обоих
- ❌ 2× model load (memory cost), сложная deployment
- ❌ Architectural complexity

### C. v8.3.3 ablation

- Train на 1-2 epochs вместо 3 (less overfit на new structural distribution)
- Возможно ещё mixed train (партиал original + регенерированный)
- Ещё ~$1-1.50 pod
- Может закрыть gap, может нет — unknown

### Recommended next move

Не выбран. Это решение Захара. До решения **v8.3.1 остаётся production**
adapter, v8.3.2 хранится как "reasoning teacher".

## Lesson candidate

**Lesson 21 (proposed)**: Stylistic features в training labels могут быть
**load-bearing** для verdict signal даже когда они выглядят шумом.
"Чистое" reasoning через teacher regeneration может разрушить случайный
stylistic anchor который модель использовала как proxy для TP-ness.
Перед full retrain — ablation на 100-200 rows чтобы посмотреть MCC delta
прежде чем тратить $3+ на full regen.

См. также Lesson 12 (FP distribution mix).
